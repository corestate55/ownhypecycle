# OwnHypeCycle

自分だけのガートナー ハイプサイクルを作成・編集できるブラウザアプリ。

## 機能

- キーワードをテーブルに入力すると、ハイプサイクル曲線上に自動描画（リアルタイム反映）
- 描画したキーワードはドラッグで位置を調整可能（所属フェーズの区間内に制約）
- テーブルデータを CSV / JSON でインポート・エクスポート
- 描画した図を SVG としてダウンロード

## 技術スタック

| 層 | 技術 |
|----|------|
| フロントエンド | React + Vite + TypeScript |
| スタイル | Tailwind CSS |
| 可視化 | カスタム SVG（外部ライブラリなし） |
| コンテナ | nginx:alpine（マルチステージビルド） |

## セットアップ

### 前提条件

- Node.js 20 以上
- npm 9 以上
- Docker（コンテナで動かす場合）

### リポジトリのクローン

```bash
git clone <repository-url>
cd ownhypecycle
```

---

## 開発サーバーでの起動

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動
npm run dev
```

ブラウザで http://localhost:5173 を開く。

ファイルを変更すると自動的にブラウザが更新されます。

### その他の開発コマンド

```bash
# TypeScript 型チェック + プロダクションビルド
npm run build

# ビルド成果物のプレビュー
npm run preview
```

## コンテナでの起動

### イメージのビルド

```bash
docker build -t ownhypecycle .
```

### コンテナの起動

```bash
docker run -p 8080:80 ownhypecycle
```

ブラウザで http://localhost:8080 を開く。

### ポートを変えたい場合

```bash
docker run -p 3000:80 ownhypecycle

```

## 使い方

### キーワードの追加

1. 画面下部の **「＋ 行を追加」** ボタンをクリック
2. テーブルのキーワード列をクリックして入力（入力と同時にチャートに反映）
3. 実現時期・フェーズをドロップダウンで選択
4. 位置 [0,1] を直接編集するか、チャート上のアイコンをドラッグして調整

### チャート上でのドラッグ

- チャート上の記号アイコンをドラッグして位置を調整できる
- 移動できる範囲はそのエントリが所属するフェーズ内に限定される
- ドラッグ中にテーブルの「位置」値がリアルタイムで更新される

### データのエクスポート

| ボタン | 動作 |
|--------|------|
| CSV | テーブルデータを `hypecycle.csv` としてダウンロード |
| JSON | テーブルデータを `hypecycle.json` としてダウンロード |
| SVG ダウンロード（右上） | チャート画像を `hypecycle.svg` としてダウンロード |

### データのインポート

1. **「CSV / JSON」** ボタンをクリック
2. ファイル選択ダイアログで `.csv` または `.json` ファイルを選択
3. テーブルとチャートが自動的に更新される

> **注意**: インポートすると現在のデータは上書きされます。

### データの保存について

データはブラウザのメモリ上にのみ保存されます。ページを閉じるとデータは消えます。
継続して使う場合は CSV または JSON でエクスポートしてください。

## 画面構成

```
┌────────────────────────────────────────────┐
│  OwnHypeCycle           [SVG ダウンロード]  │
├────────────────────────────────────────────┤
│                                            │
│  ハイプサイクル (SVGチャート)               │
│  ・曲線上に記号アイコン + ラベル            │
│  ・右上に実現時期の凡例                     │
│                                            │
├────────────────────────────────────────────┤
│  [＋ 行を追加] [CSV] [JSON] [CSV/JSON読込]  │
├────────────────────────────────────────────┤
│  キーワード | 実現時期 | フェーズ | 位置     │
│  ...                                       │
└────────────────────────────────────────────┘
```

## 実現時期の凡例

| 記号 | 値 | 意味 |
|------|-----|------|
| ○ 白丸（黒枠） | `lt2` | 2年未満 |
| ● 青丸 | `2to5` | 2〜5年 |
| ● 紺丸 | `5to10` | 5〜10年 |
| ▲ 赤三角 | `gt10` | 10年以上 |
| ⊗ 赤バツ丸 | `obsolete` | 安定期に達する前に陳腐化 |
