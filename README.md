# OwnHypeCycle

自分だけのガートナー ハイプサイクルを作成・編集できるブラウザアプリ。

## 概要

- キーワードをテーブルに入力すると、ハイプサイクル曲線上に自動描画
- 描画したキーワードはドラッグで位置を調整可能（フェーズ内に制約）
- テーブルデータを CSV / JSON でインポート・エクスポート
- 描画した図を SVG としてダウンロード

## 技術スタック

| 層 | 技術 |
|----|------|
| フロントエンド | React + Vite + TypeScript |
| スタイル | Tailwind CSS + shadcn/ui |
| 可視化 | カスタム SVG |
| コンテナ | nginx:alpine |

## 起動方法

### Docker（推奨）

```bash
docker build -t ownhypecycle .
docker run -p 8080:80 ownhypecycle
```

ブラウザで http://localhost:8080 を開く。

### ローカル開発

```bash
npm install
npm run dev
```

## 画面構成

```
┌────────────────────────────────────────────┐
│  ヘッダー                [SVGダウンロード]   │
├────────────────────────────────────────────┤
│                                            │
│  ハイプサイクル (SVGチャート)               │
│                                            │
├────────────────────────────────────────────┤
│  [行追加]  [CSVエクスポート]  [JSONインポート] ...  │
├────────────────────────────────────────────┤
│  キーワード | 実現時期 | フェーズ | 位置     │
│  ...                                       │
└────────────────────────────────────────────┘
```

## 実現時期の凡例

| 記号 | 意味 |
|------|------|
| ○ 白丸 | 2年未満 |
| ● 青丸 | 2〜5年 |
| ● 紺丸 | 5〜10年 |
| ▲ 赤三角 | 10年以上 |
| ⊗ バツ丸 | 安定期に達する前に陳腐化 |
